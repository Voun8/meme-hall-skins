# 尽欢社区装扮

这是尽欢网站气泡、徽章、称号和回应框设计的独立投稿仓库。试运行期间，用户可以复制示例、设计自己的套装并提交合并请求。提交时说明作者、名称、使用到的素材及授权情况；不需要填写复杂的审核表。

## 快速预览

安装 Node.js 后，在本仓库运行 `node serve.mjs`，打开 `http://127.0.0.1:4175/` 查看现有角色、预设、官方和个人专属气泡，可搜索、选择等级、切换明暗主题。修改 `public/` 内对应的 CSS、JS 和素材后刷新预览。预览不连接生产账号或数据库。

`public/` 保存站内现有气泡的前端样式、运行代码、注册目录和相关素材；`asset-manifest.json` 记录快照文件及 SHA-256。兼容样式 `style.css`、`chat.css` 也包含站点通用展示规则，不包含站点服务端、账户、数据库或部署凭据。`examples/simple/` 仍提供四项装扮的最简独立起点。

## 投稿

1. 直接修改已有气泡的 `public/` 样式和素材，或复制 `examples/simple` 创建新作品。
2. 在提交说明中写明作品名称、作者、素材来源与授权，并附预览图；检查长消息与手机显示。
3. 提交合并请求。试运行直接合并并接入，不另设审核平台；站点需经构建和发布才能生效。目前站点仓库与本仓库的自动同步仍在接入中，不能将本仓库的合并视为已经上线。

不要提交账号、密钥或私密数据。不要通过装扮遮挡其他人的内容、篡改网站操作或执行不相关脚本。投稿者须确保拥有素材的使用和再发布权限。站点与个人已拥有的装扮记录以主站现有逻辑为准。

仓库代码使用 MIT 许可。图片、角色及其他设计素材由各自作者在套装目录中注明授权，代码许可不会自动授予素材使用权限。
