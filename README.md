# 尽欢社区装扮

这是尽欢网站气泡、徽章、称号和回应框设计的独立投稿仓库。试运行期间，用户可以复制示例、设计自己的套装并提交合并请求。提交时说明作者、名称、使用到的素材及授权情况；不需要填写复杂的审核表。

## 快速预览

用浏览器打开 `examples/simple/index.html`，修改同目录下的 `skin.css` 即可查看示例。该页面是独立预览，展示四种装扮，不会连接或修改网站。

## 投稿

1. 复制 `examples/simple` 到 `skins/你的套装ID/`，ID 使用小写字母、数字和连字符。
2. 修改样式和素材，在该目录的 `README.md` 写明名称、作者、素材来源与授权。
3. 提交合并请求，并附一张浅色和一张深色预览图。对文字、长消息及手机宽度做基本检查。
4. 合并后由站点接入该套装并发布；目前还没有自动导入或自动上线功能。

不要提交账号、密钥或私密数据。不要通过装扮遮挡其他人的内容、篡改网站操作或执行不相关脚本。投稿者须确保拥有素材的使用和再发布权限。站点与个人已拥有的装扮记录以主站现有逻辑为准。

仓库代码使用 MIT 许可。图片、角色及其他设计素材由各自作者在套装目录中注明授权，代码许可不会自动授予素材使用权限。
